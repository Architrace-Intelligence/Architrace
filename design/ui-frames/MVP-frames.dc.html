Architrace · MVP frames

Initial release of the web UI: a Projects list that filters by project, environment and Kubernetes cluster, and a Service map for the chosen scope that shows every service, data store and data stream. Frames are 1440 × 900, dark theme, static. Flow: 1 → 2 (filter) → open a row → 3 → select a service → 4 → select a data stream → 5.

scope = project × environment × cluster · data stream = topic or queue with its producers and consumers
