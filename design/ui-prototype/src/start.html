Architrace

MVP user interface design

Interactive screens for the web UI served by the control plane: service map, drift, findings, agents and the overview, plus the foundations they share and the agent-first principles behind them. Every screen is a working prototype on demo data: click nodes, switch environments, open the Ask bar, change the theme.

Screens

one file per screen · linked through the left rail
HomeOverview Three environments at a glance: counts, agent health, findings by severity, how each differs from PROD, and what changed recently. M4Service map The real architecture per environment: services, data stores, topics and external calls, with filters, search, a time selector and a context rail for nodes and dependencies. M5Drift Two environments or two points in time of one environment, as a grouped list and as map overlays, with the consequences each difference has for the rules. M6Findings Six deterministic rules, their thresholds and their findings with evidence; passing rules are shown too, so silence is never ambiguous. M3Agents Registered agents with liveness, throughput, drops and the configuration they run with; what a stale agent means for the graph. SystemFoundations Colour tokens in both themes, type scale, node and edge encoding, badges, components and the layout grid, ready to become the React component library. PrinciplesAgent-first, before the agent Why the Ask bar, the context rail, URL state and evidence-first cards are there in an MVP that ships without AI.
Direction Calm control room Dark by default for long sessions next to terminals and dashboards, with a full light theme. One cool accent for interaction, four hues reserved for node types, red and amber reserved for severity and drift. IBM Plex Sans for text, JetBrains Mono for identifiers and numbers. Dense where data lives, generous where decisions are made.
Demo data A small shop landscape Eight services across five domains, four data stores, two Kafka topics, two external hosts; three environments and six agents. PROD carries a cycle and a shared database; DEV is one release ahead with a change that would create a second shared database. Figures are fixtures, shaped to exercise every rule and both drift modes.
Implementation notes Maps to M4, M5, M6 Shell: rail 84 px, top bar 56 px, context rail 360 px, collapsing below 1180 px and 860 px. Map nodes are React Flow custom nodes; edges carry kind, calls and error rate; layout is ELK layered left to right. Colours, spacing and radii are the CSS custom properties listed on the Foundations page.
